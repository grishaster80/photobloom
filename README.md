# PhotoBloom — website

Marketing, support, and privacy pages for the **PhotoBloom** iOS app, served via GitHub Pages.

| Page | Purpose | App Store field |
|------|---------|-----------------|
| `index.html` | Landing / marketing | Marketing URL |
| `support.html` | Support + FAQ + contact | Support URL |
| `privacy.html` | Privacy policy | App Privacy → Privacy Policy URL |

Plain static HTML + one CSS file (`assets/style.css`). No build step.
